# Project Guidelines & Rules

## Git Commit Style
- **Never** use conventional commit prefixes or scopes (such as `feat(ui):`, `feat(api):`, `fix:`, `chore:`, etc.).
- Always use natural, human commit messages written in simple, lowercase action phrases:
  - Example: `added class hierarchy schema and sqlite database operations`
  - Example: `integrated gemini question extraction and zero temperature evaluation`
  - Example: `created organization, class and student roster management`
  - Example: `fixed question matrix layout and optimized latency`
- Commit and push changes incrementally in clean, logical human-style slices.
